先說最重要的

這是朋友間測試的非官方小工具，不是 Riot 或 League of Legends 官方程式。它的設計重點是唯讀、留在本機，以及不碰原本隱藏的玩家身分。

不需要帳號密碼 程式沒有登入畫面，也不會要求你輸入 Riot 帳號、密碼或驗證碼。
不注入、不改遊戲 不讀取遊戲記憶體、不模擬按鍵、不修改 LoL 檔案，也不替你做遊戲操作。
不把玩家資料傳出去 沒有本工具自己的遠端伺服器、廣告或使用分析；本場玩家資料不會上傳。
不查歷史戰績 不連線第三方戰績網站，不根據牌位、過往勝率或長期 KDA 評論玩家。
不破解匿名玩家 選角時 LoL 沒有公開的玩家會保持匿名，正常揭露後才顯示。
不需要管理員權限 使用一般 Windows 使用者權限執行；登入 Windows 後常駐預設為關閉。
⚠
仍然要知道：這是未簽章的個人測試版，Windows 可能顯示「未知發行者」。它使用 Riot 未保證長期相容的本機資料介面，LoL 更新後可能暫時失效。任何第三方工具都不應宣稱零風險；如果你不願使用非官方工具，直接不要執行即可。

30 秒開始

請從你認識的分享者取得完整 ZIP，先解壓縮，再執行裡面的 EXE。不要執行陌生人重新上傳或改過檔名的版本。

完整解壓縮

在 ZIP 上按右鍵選「解壓縮全部」，進入解壓後的資料夾。不要直接在壓縮檔預覽中執行。

雙擊 EXE

開啟 LoL即時表現Overlay.exe。它平常只待在 Windows 右下角系統匣，所以沒有跳出主視窗是正常的。

照常開啟 LoL

進入選角後會自動出現資訊條；遊戲開始時會縮成圓點。結束對局後約 15 秒自動隱藏。

第一次執行出現 Windows SmartScreen 怎麼辦？

未簽章的個人程式常會顯示「Windows 已保護您的電腦」或「未知發行者」。只有在檔案是你直接向分享者取得，而且進階區的 SHA-256 一致時，才選擇「其他資訊／更多資訊」→「仍要執行」。這個警告來自缺少商業程式碼簽章，本身不能證明安全，也不能證明有問題。

你會看到什麼

顯示共有三種大小。進入遊戲後預設縮成圓點，只有你主動點擊或按快捷鍵時才展開。

顯示已選英雄、可見人數與匿名位置，不會替匿名位置查身分或評分。

遊戲中：圓點

遊戲開始時自動縮成圓點。點一下可展開，不會搶走 LoL 的鍵盤焦點。

可以把它想成一張放在遊戲上方的「本機計分紙」。資料不必先傳到別人的網站，程式就在你的電腦裡讀取、計算與顯示。

→
Overlay圓點／資訊條／面板
↳ 另一條獨立支線：程式向 Riot 的公開靜態素材服務下載英雄與物品名稱、價格及圖示，存成本機快取；請求不會附帶玩家資料。

分數怎麼來

分數只回答「這場目前打得如何」，不是牌位、長期實力、勝率或對一個人的定論。

這一場的投入綜合擊殺參與、生存、等級、吃兵與裝備等當場資料。
考慮英雄定位輔助、坦克、法師等使用不同權重，避免只用輸出角色標準判斷。
同場相對比較和這場十人比較，不拿過去牌位或歷史戰績當依據。
逐步增加信心開局維持接近中性並平滑更新，避免一次事件造成誤判。

資料會讀、會存、會傳嗎？

「寫入硬碟」和「上傳」是不同事情。程式會保存顯示設定與公開素材快取，但不把玩家對局明細寫成歷史檔，也不把它傳出去。

常見疑問

它會不會修改或控制 LoL？

不會。程式只向 League Client 與遊戲本身在同一台電腦提供的唯讀資料介面取得資訊。它不注入程式碼、不讀取遊戲記憶體、不修改遊戲檔案，也不模擬滑鼠或鍵盤操作。

它會不會偷偷上傳玩家資料？

目前版本沒有玩家資料上傳、廣告或分析追蹤功能，也沒有本工具自己的遠端伺服器。唯一的網際網路下載是 Riot 公開的英雄與物品靜態素材。

為什麼防毒或 SmartScreen 可能提醒？

這是沒有購買商業程式碼簽章的單檔個人測試程式，因此 Windows 可能無法辨識發行者。警告本身不是安全認證，也不代表一定有問題；請只使用你直接從認識的分享者取得並核對過雜湊的檔案。

可以保證完全不會有帳號風險嗎？

不能誠實地做這種保證。它的設計避開注入、控制遊戲、隱藏身分還原與未知資訊，但仍然是非官方第三方工具。若你不能接受任何第三方工具的不確定性，請不要執行。

為什麼選角有人仍顯示匿名？

因為程式尊重 LoL 原本的隱藏設計。只有 League Client 正常提供身分時才顯示，沒有提供的玩家不會另外查找或推測。

它會保存我打過哪些人嗎？

不會寫入玩家歷史或詳細對局紀錄。本場資料只在程式記憶體內用於當下計分；硬碟上只會留下顯示設定和英雄／物品素材快取。

沒有顯示或位置不對

雙擊後完全沒有主視窗

這通常是正常的。程式會待在工作列右下角系統匣，只有選角、載入或遊戲中才顯示 Overlay。先點右下角「︿」查看隱藏圖示。

進入遊戲後還沒出現資料

從選角切換到載入畫面時，本機遊戲資料可能需要幾秒才開始提供。先等待載入完成；若持續沒有資料，可重新啟動 Overlay 和 League Client。

快捷鍵沒有反應

預設是 Ctrl + Shift + O。若已被其他程式使用，會改用 Ctrl + Shift + F9。可以從系統匣右鍵開啟「設定」查看或修改。

Overlay 跑到螢幕外或舊螢幕

從系統匣右鍵開啟「設定」，選擇「重設位置」並儲存。程式會把 Overlay 移回目前可見的螢幕範圍。

LoL 更新後突然不能用

這個工具依賴 Riot 沒有保證永久相容的本機介面。若更新改變資料格式，程式可能暫時只顯示等待或完全隱藏；請把版本與發生階段回報給分享者。

如何完整移除？

先從系統匣「設定」關閉登入 Windows 後常駐，再從系統匣選「結束」，最後刪除 EXE。若想連設定與素材快取一起刪除，按 Win + R，貼上 %LOCALAPPDATA%\LolPerformanceOverlay，確認路徑正確後刪除該資料夾。

回報問題

按鈕只把下面的文字複製到剪貼簿，不會自動傳送任何資料。填好後自行貼給分享者；若方便，附上一張 Overlay 截圖最有幫助。

實際連線目的地

  • 127.0.0.1：只代表你的這台電腦。程式用它讀取 League Client 階段、選角資料與本場即時資料。
  • https://ddragon.leagueoflegends.com：Riot 的公開靜態素材服務，用來下載版本、繁體中文英雄／物品資料與英雄圖示。
  • 程式對上述來源只執行讀取／下載；沒有玩家資料上傳請求。

會留在電腦上的內容

  • %LOCALAPPDATA%\LolPerformanceOverlay\settings.json：位置、透明度、快捷鍵與是否開機常駐。
  • %LOCALAPPDATA%\LolPerformanceOverlay\cache：Riot 公開的英雄／物品資料與圖示。
  • 只有主動開啟「登入 Windows 後常駐」時，才會在目前使用者的 Windows 啟動項目加入 EXE 路徑。
