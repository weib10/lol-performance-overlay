先看安全，再開始使用

LoL 即時表現 Overlay 是非官方、唯讀的桌面小工具。它把這一場已經提供的資料整理成低干擾提示，不替你操作遊戲，也不要求帳號、密碼或管理員權限。

安全與隱私邊界

先確認這些行為符合你的接受範圍；若不願使用任何非官方工具，最安全的選擇就是不要執行。

不需要登入資料沒有登入畫面，不要求 Riot 帳號、密碼、驗證碼或任何開發者憑證。
不控制或修改遊戲不注入程式、不讀取遊戲記憶體、不模擬按鍵或滑鼠，也不修改 LoL 檔案。
玩家資料留在本機記憶體本場資料用完即丟，不寫成對局歷史，不上傳，也沒有廣告或使用追蹤。
尊重匿名玩家遊戲沒有公開身分時就維持匿名；程式不嘗試還原、猜測或跨站追查。
一般使用者權限即可不需要系統管理員權限；登入 Windows 後自動啟動預設關閉。
外部下載只有公開素材程式只向 Riot 的公開素材服務下載英雄名稱與圖示；請求不附帶玩家資料。

請注意Windows 可能顯示未知發行者

這個 EXE 尚未購買商業程式碼簽章，SmartScreen 或防毒軟體可能提醒。警告不代表檔案一定有問題，也不是安全保證。只使用你直接從可信分享者取得的完整 ZIP，並核對本頁底部的 SHA-256；來源或雜湊不一致就不要執行。

這是候選成品，仍需在 Windows 真機完成 SmartScreen、不同螢幕縮放、多螢幕、焦點和完整 LoL 對局驗收，因此不宣稱已達穩定發布門檻。

30 秒開始

ZIP 解壓後應該只有 LoL即時表現Overlay.exe 和這份 先看這裡.html。

完整解壓縮

在 ZIP 上按右鍵選「解壓縮全部」。不要直接從壓縮檔預覽執行 EXE。

雙擊 EXE

程式啟動後會待在工作列右下角的系統匣；沒有傳統主視窗是正常的。若圖示被收起，先點工作列的「︿」。

照常開啟 LoL

選角或進入對局後 Overlay 會自動出現。LoL 尚未啟動、資料暫時未提供或對局結束時，程式會等待、重試或隱藏，不需要重複開啟。

拖曳、切換、鎖定與找回

三種顯示大小使用同一套規則：未鎖定時可以移動；鎖定後整個 Overlay 不接收滑鼠，避免攔截遊戲操作。狀態除了顏色也會用文字說明。

圓點

按住圓點任何位置都能拖曳。短按且沒有明顯移動才會切換大小；拖曳不會同時觸發切換。

精簡資訊條

按住按鈕以外的大部分背景即可拖曳。顯示雙方本場相對表現、差距和白話狀態。

完整面板

同樣可從非按鈕背景拖曳；每一列會併排顯示官方牌位短碼（例如 D4）與本場相對表現分數，兩者分開呈現，滑鼠移到列上可看到完整資訊。

常用控制

  • 切換大小：點擊圓點、使用面板按鈕，或按 Ctrl + Shift + O。若組合鍵已被其他程式占用，系統匣設定會顯示實際可用的快捷鍵。
  • 鎖定位置：從系統匣或設定開啟「鎖定位置」。鎖定後 Overlay 內的按鈕也不接收滑鼠；請用快捷鍵或系統匣切換顯示，要搬動時先從系統匣解除鎖定。
  • 視窗不見：在系統匣選「顯示」；若換過螢幕或縮放比例，選「重設位置」把 Overlay 帶回目前可見範圍。
  • 結束程式：在系統匣選「結束」。只關閉 LoL 不一定會關閉 Overlay。

畫面上的資訊代表什麼

本場即時表現 只比較這一場目前已發生的狀況。它不是官方牌位、長期實力、隱藏分數、勝率預測，也不是針對玩家的遊戲指令。
歷史近期狀態／風格 程式已能查詢官方牌位，但需要你自己申請、貼進設定的 Riot 個人 API key（只存在你的電腦，不隨程式附上）。沒有貼 key 時會誠實顯示「目前無法取得」，不會用假資料冒充真人結果，也不影響本場 Overlay。

想自行查看公開資料

你可以選擇在瀏覽器開啟 OP.GG 首頁（需要網路），再自行搜尋遊戲已正常公開的玩家。這只是一般瀏覽器連結：Overlay 不讀取該頁、不存取瀏覽器資料、不自動抓取網站內容，也不查找匿名玩家。

疑難排解

雙擊後沒有主視窗

先看工作列右下角系統匣；沒有對局時 Overlay 本來就可能隱藏。點「︿」查看收起的圖示，再從圖示選「顯示」。

進入遊戲後仍在等待

載入期間資料可能短暫中斷，程式會自動重試。若進入遊戲數分鐘後仍沒有資料，依序重新啟動 Overlay 與 League Client。不要用系統管理員身分執行其中一個、一般權限執行另一個。

拖曳時反而切換大小

確認位置沒有鎖定，再按住後移動。圓點只有在放開前幾乎沒有移動時才算點擊；若真機仍誤觸，請記下 Windows 縮放比例、滑鼠或觸控板類型後回報。

Overlay 擋住遊戲點擊

在系統匣開啟「鎖定位置」；整個 Overlay 就不應接收滑鼠，控制按鈕也需先從系統匣解除鎖定才可使用。若鎖定後仍擋住，先隱藏 Overlay 並回報發生的模式與位置。

換螢幕後 Overlay 不見

從系統匣選「重設位置」。程式會依目前可見的螢幕工作區校正位置；重新啟動後也應停在合理範圍。

LoL 更新後突然失效

LoL 的本機資料格式可能改變。Overlay 應維持等待並重試，不會改讀遊戲記憶體或用其他高風險方式繞過。請將程式版本、發生階段與白話狀態訊息回報給分享者。

完整移除

  1. 從系統匣設定關閉「登入 Windows 後自動啟動」。
  2. 從系統匣選「結束」。
  3. 刪除解壓後的 EXE、HTML 與原始 ZIP。
  4. 若也要清掉設定與公開素材快取，按 Win + R，貼上 %LOCALAPPDATA%\LolPerformanceOverlay，確認資料夾名稱正確後刪除。

程式沒有系統服務、驅動程式或額外 App；完成上述步驟後就不會留下常駐元件。
